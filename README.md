# 📝 Simple Text Editor

A lightweight **Python Tkinter application** that provides basic text editing functionality with a clean GUI. This project demonstrates how to build a simple desktop text editor with options to create, open, edit, and save text files.

---

## 🚀 Features
- **New File** → Clear the editor to start fresh.  
- **Open File** → Load existing `.txt` files into the editor.  
- **Save File** → Save your work as a `.txt` file.  
- **Exit** → Close the application safely.  
- **Text Area** → Editable text box with word wrapping, custom font, and blue text color.  

---

## 🛠️ Tech Stack
- **Python 3.x**  
- **Tkinter** (GUI framework)

## ▶️ How to Run
1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/SimpleTextEditor.git
   ```
2. Navigate to the project folder:
   ```bash
   cd SimpleTextEditor
   ```
3. Run the script:
   ```bash
   python main.py
   ```
